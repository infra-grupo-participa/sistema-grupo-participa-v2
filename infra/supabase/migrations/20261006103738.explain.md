## 1. O erro

`public.crm_ofertas` (F1, `20261005s`) montava `linkCheckout = 'https://pay.hotmart.com/' || produto_id || '?off=' || código`.
`produto_id` é o id **numérico** do produto (7 dígitos). Ele não é o código de checkout do produto.

**Decisão:** usar o link da própria Hotmart (mesma expressão da F5). O formato `pay.hotmart.com/<código de checkout>?off=` só é
conhecido para 3 produtos; misturar as duas formas criaria duas regras. Se o negócio quiser o caminho com o código do produto,
precisa antes do código de checkout de todos os produtos (pergunta para o Marcio/gestor, não chutar).
Obs.: `curl` nas 3 formas devolve HTTP 200 (página SPA) — não prova nada; a fonte é o dado da Hotmart.
